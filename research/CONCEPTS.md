## The specimen

**Beat:** Beat 5, what ships. This concept is beat 5 done as an object instead of a list.

**The idea in two sentences:** Instead of listing the eight schema fields and the six-item consent stack as bullets, render one single delivered clip as its own record: a precise, typeset artifact that reads like a Sotheby's lot card crossed with a chain-of-custody form, every field present, the provenance ID sealing it at the bottom. A data company that shows you the receipt instead of the pitch is doing the exact thing its buyer's counsel is about to ask for, before they ask.

**Why it is right for this company specifically:** The entire moat in BRIEF.md is "a consent and provenance stack that survives a buyer's legal review." No robotics company documents a chain of custody, so the artifact positions by depth with no denial needed, which is the no-negation rule satisfied by construction. The old-money scouts all converge on one finding: expensive pages show the thing (Klim's Fonts in Use, Sotheby's lot data, Patagonia's procedures) and cheap pages assert. The specimen is that finding applied to a clip. It is also the strongest answer to the buyer's second question, is the rights story clean, because it answers it with a document rather than an adjective.

**Buildable tonight, honestly:** Yes. It is DOM, type, and hairlines. Every value is already in FACTS.md (the eight annotation fields, the six provenance items, POPIA Section 57, C2PA signing). It is composed as a document with rules, never a card with a border, so it obeys the LOOK.md ban on boxing. Optional stretch: the provenance ID line alone types itself in once and a hairline draws under it like a seal, reusing the Helix typewriter grammar that Jay already likes. That stretch conflicts with the LOOK.md rule that the schema and provenance tables never move, so the reconciliation is to animate only the single ID line, never the table, and to fall back to a fully static seal if arbiter holds the line. Flagging that tension honestly rather than hiding it.

**Assets needed:** None generated. One example provenance record, invented in structure but populated only with true field names and true schema values, never a fabricated hours count, buyer, or site. The example clip is described generically (task label, environment tag, geography tag, hand-visibility flag, and so on) so no forbidden fact is implied.

**Credits:** 0.

**How it fails:** It fails if it reads as a spec table with a border instead of an object with weight, which is a composition problem, not an idea problem. It fails if the field values feel like filler, so each field must carry one real, specific detail (21-keypoint hand-pose track where recoverable, consent and provenance ID linking the clip to a signed release). It fails hardest if anyone drops a placeholder number into the example to make it look populated, which is the one thing FACTS.md forbids most sharply; the record must be honest that it is a schema, not a delivered inventory.

## The source in its own tongue

**Beat:** Beat 6, why it is done this way. The ethos beat, forest, full bleed.

**The idea in two sentences:** The consent is signed in the participant's own language, English, Afrikaans, or isiXhosa, so put the language on the page as the emotional core of the ethos beat, the worker present through their tongue rather than their body. It is the one honest way to make the human present in a section that forbids showing a human, and it turns the hardest constraint on the site into its most human moment.

**Why it is right for this company specifically:** The Palantir problem in BRIEF.md is that a company filming dangerous work can read as harvesting people. The fix is to make the person the source and never the spectacle, and language does that precisely: it centres the person without turning them into an image to be consumed. FACTS.md verifies the three languages, and the multilingual release is a procedure a buyer can check, which is the Patagonia and Kickstarter pattern from the ethics scout, a trust move you can verify beating a label you must believe. No competitor scouted does this; every robotics buyer page is monolingual English and technical.

**Buildable tonight, honestly:** Yes for the safe tier. The safe tier names the three languages as a typographic triad in the display serif on forest, set against one true sentence in the company's first-person voice drawn from the ethos, with zero fabricated translation. The bold tier sets the same short consent line in all three languages at once, which is far stronger but requires a verified isiXhosa and Afrikaans rendering; inventing that text would be a fabrication under the FACTS-or-nothing rule, so the bold tier is gated on a real translated line and logged to findings/needs-fact.md rather than guessed. Ship the safe tier tonight, leave the bold tier as a one-line swap for Jay.

**Assets needed:** None generated. Type only. For the bold tier, one verified translated consent line per language, which is a fact request, not an asset.

**Credits:** 0.

**How it fails:** It fails if it fabricates a translation to look complete, which is a P0 under the fact ledger, so the bold tier stays gated. It fails if it reads as decorative multilingualism, a flag-emoji gesture, rather than a procedure, so it must sit next to the plain statement that consent is signed before recording in the participant's language. It fails if the isiXhosa is set in a face that lacks the diacritics or the click-consonant orthography renders wrong, which would be worse than not attempting it, so the safe tier ships unless the type is verified.

## First light on the Western Cape

**Beat:** Beat 4, the method. The window and the place, Western Cape harvest, July 2026 to approximately January 2027.

**The idea in two sentences:** One generated aerial of the actual operating ground, Western Cape vineyards in winter harvest light, empty of people, matte-graded into bone, ink, and forest, sitting in a column beside the method copy. It grounds the claim that someone actually went there, this season, in a real place, without a single worker in frame.

**Why it is right for this company specifically:** Specificity is the old-money flex from every scout, 15 July 2026 and ZRS Arkitekten read expensive, "premium" reads cheap; a named, real, current place does the same work for the method. It is exactly the class of image the provenance law permits, an unpopulated environment, terrain and aerial, so it costs nothing in integrity. And it answers the buyer's third question, will this person deliver, with a place instead of a promise: the operation is somewhere specific, now.

**Buildable tonight, honestly:** Yes, with generation risk. It is one plate, but empty landscapes drift toward stock postcard, and the palette must be forced cold and matte since amber is retired, so budget several iterations. LOOK.md bans full-bleed photography below the daylight cut and caps imagery at 45% of any horizontal slice, so this lands as a column image beside text, never a bleed, which also protects the luminance gate.

**Assets needed:** One final environment plate. Model: Nano Banana 2 at 2k, 21:9 or 16:9, for a fast photorealistic terrain pass, or Seedream 4.5 if a 4K matte is wanted for retina columns. Expect three to six generations to land one usable frame plus one optional upscale. Absolutely no people, no vehicles with visible operators, no head-mounted rigs; empty rows, empty light.

**Credits:** About 40 to 50, conservative, covering iteration and one upscale. Could be as low as 15 if the first pass lands. This is the only concept here that spends anything.

**How it fails:** It fails if it looks like a wine-country tourism photo, which quietly destroys the credibility of a company whose whole claim is that it films the real thing; the grade has to pull it toward document, not brochure. It fails if it ever reads as captured footage rather than an atmosphere plate, so it must sit clearly as environment, never captioned as data. It fails the gate if it creeps to full bleed and eats light bands, so the column constraint is not optional.

## The record, drawn to scale

**Beat:** Beat 3, the turn. Where the indoor record is shown to exist and the outdoor record is shown to be empty.

**The idea in two sentences:** A quiet, precise measure that draws the existing egocentric record as a filled block, Ego4D at 3,670 hours, cited, against the outdoor record rendered as a void of the same frame, empty. The emptiness is the image, the gap made literal, and it makes the missing input impossible to miss before the daylight cut answers it.

**Why it is right for this company specifically:** Beat 3 is the load-bearing beat, the place the negation dies and the camera stops being random, per BRIEF.md and STORY.md. The turn rests on one fact, that the reference corpora were shot indoors and the outdoor record is empty, and this shows that fact at true proportion instead of asserting it. The NVIDIA GEAR scout is explicit that the strongest research communication gives you the number and lets you verify the claim structure yourself; a drawn-to-scale measure is that instinct, and it names no competitor, so it obeys the anonymity rule.

**Buildable tonight, honestly:** Yes. It is layout, type, and maybe a little SVG, no generation. The only hard constraint is that every number matches FACTS.md exactly, Ego4D 3,670 hours as worded, and that no Vallum Labs quantity ever fills the empty side, because there is no captured-hours number and inventing one is forbidden. The empty side stays empty on purpose, which is the whole point.

**Assets needed:** None generated. Type and rule only.

**Credits:** 0.

**How it fails:** It fails if it competes with the daylight cut and overloads the one beat that already owns the site's signature, which is a real risk and the honest reason this ranks last; arbiter may cut it precisely to protect the cut, and that would be correct. It fails if it reads as generic dashboard data-viz, which the register forbids, so it must be a single restrained measure, not a chart. It fails if the void reads as unfinished rather than deliberate, so the empty side needs a caption that owns the absence, the record is empty and that is the company's reason to exist.

## Decisions made

- [dreamer] chose mechanics and composition over generated imagery for three of four concepts because the provenance law forbids generating the one compelling thing, a person at work, so the boldness had to move into things that cost zero credits and carry zero integrity risk.
- [dreamer] chose to put the dreamer's one founder-level swing on beat 5 rather than compete with the Helix on beat 2 or the daylight cut on beat 3, because both of those beats already have their set piece and the light half of the page had none.
- [dreamer] chose the provenance specimen as the top concept over the aerial because it has perfect beat-fit, zero generation risk, zero fact risk, and is uniquely right for a company whose entire moat is a record that survives legal review.
- [dreamer] chose to rank the Western Cape aerial above the record-to-scale measure on beat-fit grounds, because beat 4 has an open lane while beat 3 already owns the site's signature, so a clean concept in an empty lane fits its beat better than a strong concept crowding a full one.
- [dreamer] chose language over image for the ethos beat because it is the only honest way to make the worker present without their body, and it turns the site's hardest constraint into its most human moment.
- [dreamer] chose to gate the bold multilingual tier of concept 2 behind a verified translation and log it rather than fabricate isiXhosa or Afrikaans text, because a fabrication and a placeholder are the same failure under the fact ledger.
- [dreamer] chose to flag the LOOK.md conflict in concept 1, that schema and provenance tables never move, in the open with a static fallback, rather than propose an animated table quietly, because the arbiter should decide the tension with the tension visible.
