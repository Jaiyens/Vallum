Side-by-side crop of `artifacts/1440/home.png` at the hero (y≈790-900) versus beat 7 (y≈9350-9450): the identical string "VALLUM LABS" is set in a heavy, tightly-spaced geometric/slab sans in the hero, and in a light-weight, widely letter-spaced Newsreader serif in beat 7. `LOOK.md`'s decision log is explicit that this was a deliberate, singular choice: "[art-director] dropped Archivo and reset the wordmark in Newsreader spaced caps because a second grotesk bought nothing and spaced serif caps is the old money wordmark grammar (Sotheby's, Aesop's Optima lockup)." The hero lockup was not reset; it is still the dropped grotesk treatment the decision log says was removed.

What it costs: the single most-repeated brand asset on the page contradicts itself within one scroll, which is the opposite of the "old money" restraint the type system is built around, and reads as unfinished or auto-generated rather than considered.

Fix as a value: set the hero `<h1>` "VALLUM LABS" to the same beat-7 treatment: Newsreader 500, all caps, `letter-spacing: 0.32em`, sized per the existing `clamp(64px, 11vw, 160px)` rule (or the hero's own display-1 step if a smaller hero lockup is intended), replacing the current bold grotesk weight/face entirely.
