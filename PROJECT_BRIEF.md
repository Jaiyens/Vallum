## Company
Vallum Labs. Tagline: "The physical internet for dangerous outdoor work." Vallum collects consent-cleared, action-labeled, first-person (egocentric) video of real dangerous outdoor manual work (farming, construction, solar installation, oil rigs) and licenses it to robotics foundation-model labs. Founder: Jaiyen, solo, pre-revenue. This is a single-page marketing site.

## Non-negotiable copy rules
No em dashes anywhere. Short declarative sentences. Sentence-case headings only. Never use the words revolutionize, unleash, or empower. No fake customer logos, no fake statistics, no invented proof.

## Tech stack (locked)
Next.js (App Router) + TypeScript + Tailwind CSS + shadcn/ui. Animations: GSAP + ScrollTrigger via @gsap/react (useGSAP hook) as the backbone; Motion (package "motion", formerly Framer Motion) for entrance and hover micro-interactions. Do NOT install react-spring. Do the hardware exploded view in GSAP. Self-host fonts with next/font. Deploy target: Vercel.

## Design tokens
Theme: dark. Colors: base ink #0A0C0B, surface #14181A, hazard amber #FFB400 (primary accent, one CTA color), data green #3BF07A (annotation overlays and small data cues only), text primary #F4F2EC, text muted #8A928F. Fonts: display = Geist (heavy weights), body = Inter, mono = Geist Mono (use tabular-nums for all figures). *(Amended: display = Archivo Expanded Bold, body = Inter, mono = JetBrains Mono.)* Spacing: 4px scale, 12-col grid, max width 1280px, section padding 120px desktop / 72px mobile. Minimal border-radius on data panels, slight radius on buttons only. This palette and the amber accent are deliberate choices; do not drift toward generic AI defaults (no cream+serif+terracotta, no single-acid-accent cliché).

## Engineering requirements
- All animation on transform/opacity/clip-path only. Zero layout shift; set width/height on media. 
- Videos: <video autoPlay muted loop playsInline preload="none" poster=...>, provide .webm and .mp4 sources, strip audio, object-cover. Preload only the hero poster with fetchPriority high.
- Register GSAP plugins once centrally. Every GSAP/Motion file is "use client". Use useGSAP with a scope ref for automatic cleanup.
- Accessibility: one h1, hierarchical headings, alt text, aria-labels on icon buttons, visible focus, color-scheme: dark on html, meta theme-color #0A0C0B, contrast >= 4.5:1 body. Respect prefers-reduced-motion globally.
- Responsive at 360/768/1280 with no horizontal scroll and no clipped text.
- File structure: app/(page.tsx, layout.tsx, globals.css), components/sections/*, components/ui/* (shadcn), lib/gsap.ts (registration), lib/tokens or tailwind theme extension, public/video, public/rig. Keep a PROJECT_BRIEF.md with tokens and the copy deck.
